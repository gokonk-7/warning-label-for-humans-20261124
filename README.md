The funniest single-line safety warning label that should come printed on every human being — one line, 160 characters or fewer, funny first and plausible second. Entry for make.fun's "Warning Label for Humans: One Line, Big Laugh" bounty.

The label:

> WARNING: Contents include a human who read the headline, skipped the article, and has opinions.

## Run it

```sh
node main.ts && cat /output/entry.txt
```

This writes the one-line entry to `/output/entry.txt` (set `OUTPUT_PATH` to write it elsewhere when testing locally). It needs nothing but Node 22+ and no network access.
